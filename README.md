## Proyectos Destacados

### HabitTracker
Aplicación web para el seguimiento de hábitos con sistema de progreso, rachas, estadísticas y autenticación.

Funciones principales:
- Registro e inicio de sesión
- Creación y gestión de hábitos diarios y semanales
- Sistema de puntos y niveles
- Progreso individual por hábito
- Persistencia de datos en el navegador

Tecnologías:
- Frontend en React
- Backend en desarrollo
- Persistencia local

Repositorio:
https://github.com/ISAACVARGAS6/HabitTracker

---

### LifePlanner
Aplicación móvil para Android enfocada en la gestión de proyectos y tareas personales, con organización por prioridades y seguimiento de progreso.

Funciones principales:
- Creación de proyectos y tareas
- Relación entre proyectos y subtareas
- Gestión de prioridades
- Visualización de listas de tareas
- Conexión entre frontend móvil y backend

Tecnologías:
- Frontend en React Native
- Backend en FastAPI (Python)
- API REST

Repositorio:
https://github.com/ISAACVARGAS6/LifePlanner
